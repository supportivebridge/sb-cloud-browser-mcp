# SB Cloud Browser

A private, always-on Chrome browser in the cloud (UK server) that Claude controls through a connector, so Claude's scheduled tasks and browser work keep running when your computer is off or Chrome is closed. You log in to your websites yourself; Claude never sees your passwords.

**Connector address:** `https://mcp.cloudbrowser.supportivebridge.com/mcp` (OAuth sign-in)

In Claude: **Settings → Connectors → Add custom connector**, paste the address above, then sign in with your SB Cloud Browser email and password.
